Tanuld meg, hogyan használhatod a billentyűparancsokat a jegyzetekben való navigáláshoz és szerkesztéshez. Egyéni [[Hotkeys|gyorsbillentyűket]] is beállíthatsz.

## Windows és Linux billentyűparancsok

### Gyakori műveletek

| Művelet | Billentyűparancs |
|-|-|
| Másolás | `Ctrl+C` |
| Kivágás | `Ctrl+X` |
| Beillesztés | `Ctrl+V` |
| Beillesztés formázás nélkül | `Ctrl+Shift+V` |
| Visszavonás | `Ctrl+Z` |
| Újra végrehajtás | `Ctrl+Shift+Z` vagy `Ctrl+Y` |
| Bekezdés másolása | `Ctrl+C` (ha nincs kijelölt szöveg) |
| Bekezdés kivágása | `Ctrl+X` (ha nincs kijelölt szöveg) |

### Szöveg szerkesztése

| Művelet | Billentyűparancs |
|-|-|
| Új sor beszúrása | `Enter` |
| Előző karakter törlése | `Backspace` |
| Következő karakter törlése | `Delete` |
| Előző szó törlése | `Ctrl+Backspace` |
| Következő szó törlése | `Ctrl+Delete` |
| Jelenlegi sor törlése | `Ctrl+Shift+K` (ha nincs kijelölt szöveg) |

### Szöveg navigációja

| Művelet | Billentyűparancs |
|-|-|
| Kurzor mozgatása egy karakterrel | `Balra/jobbra nyíl` |
| Kurzor mozgatása az előző szó elejére | `Ctrl+Balra nyíl` |
| Kurzor mozgatása a következő szó végére | `Ctrl+Jobbra nyíl` |
| Kurzor mozgatása az aktuális sor elejére | `Home` |
| Kurzor mozgatása az aktuális sor végére | `End` |
| Kurzor mozgatása az előző sorba | `Fel nyíl` |
| Kurzor mozgatása a következő sorba | `Le nyíl` |
| Kurzor mozgatása a jegyzet elejére | `Ctrl+Home` |
| Kurzor mozgatása a jegyzet végére | `Ctrl+End` |
| Kurzor mozgatása egy oldalnyit fel | `Page Up` |
| Kurzor mozgatása egy oldalnyit le | `Page Down` |

### Szöveg kijelölése

| Művelet | Billentyűparancs |
|-|-|
| Kijelölés egyszerűsítése | `Escape` |
| Összes kijelölése | `Ctrl+A` |
| Kijelölés kiterjesztése egy karakterrel | `Shift+Balra/jobbra nyíl` |
| Kijelölés kiterjesztése az előző szó elejéig | `Ctrl+Shift+Balra nyíl` |
| Kijelölés kiterjesztése a következő szó végéig | `Ctrl+Shift+Jobbra nyíl` |
| Kijelölés kiterjesztése az aktuális sor elejéig | `Shift+Home` |
| Kijelölés kiterjesztése az aktuális sor végéig | `Shift+End` |
| Kijelölés kiterjesztése a jegyzet elejéig | `Ctrl+Shift+Home` |
| Kijelölés kiterjesztése a jegyzet végéig | `Ctrl+Shift+End` |
| Kijelölés kiterjesztése egy oldalnyit fel | `Shift+Page Up` |
| Kijelölés kiterjesztése egy oldalnyit le | `Shift+Page Down` |

| Művelet | Billentyűparancs |
|-|-|
| Másolás | `Cmd+C` |
| Kivágás | `Cmd+X` |

| Újra végrehajtás | `Cmd+Shift+Z` |
| Bekezdés másolása | `Cmd+C` (ha nincs kijelölt szöveg) |
| Bekezdés kivágása | `Cmd+X` (ha nincs kijelölt szöveg) |

### Szöveg formázása

| Művelet | Billentyűparancs |
| ---- | ---- |
| Félkövér szöveg | `Cmd+B` |
| Dőlt szöveg | `Cmd+I` |

| Jelenlegi sor végéig törlés | `Cmd+Delete` |
